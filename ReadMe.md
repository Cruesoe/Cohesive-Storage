# Cohesive Storage

RimWorld 1.6 patch mod that folds [Path of The Muffalo](https://steamcommunity.com/sharedfiles/filedetails/?id=3541722499) storage into vanilla-style era research.

Requires [Adaptive Storage Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3033901359). Incompatible with Progression: Storage.

## Research

Four Main-tab projects replace the extra storage techs those mods add:

| Project | Cost | Unlocks |
|---|---|---|
| Neolithic storage | 200 | Adaptive Neolithic buildings, Phaneron pot |
| Medieval storage | 500 | Most Phaneron and Neat crates, pallets, shelves, food, meat, textiles |
| Industrial storage | 1000 | Metal crates, dumpster, cargo, safe, drum, fridges |
| Spacer storage | 2000 | Gravship storage; cryogenic tanks also need Cryptosleep |

## Supported mods

- Adaptive Storage Neolithic Module
- Phaneron's Basic Storage
- [sbz] Neat Storage
- [sbz] Fridge
- [sbz] Gravship Storage
- [sbz] Cryogenic Tank
- Vanilla Furniture Expanded
- Vanilla Furniture Expanded - Spacer Module
- Vanilla Recycling Expanded
- Hospitality: Vending machines
- Vanilla Factions Expanded - Medieval 2

When Phaneron and Neat Storage are both loaded, Neat's three pallets are hidden so Phaneron's remain.
